🔒 設定訪客模式解鎖密碼

呢個密碼係用嚟喺「訪客模式」之下解鎖返編輯權限。
密碼會用 SHA-256 加密咗再同步去你嘅 Google 帳號，原文唔會儲存。
請揀一個你記得住、但屋企人唔會估到嘅密碼。
⚠ 加鹽用嘅 pepper 係寫死喺呢份公開 source 入面嘅，即係話短密碼一旦俾人攞到個 hash，幾秒就爆得晒。所以請用長啲、唔規則嘅密碼（例如夾三個唔相干嘅字加數字），唔好用生日或者小朋友個名。

⚙ AI API 設定

🔒 呢三格資料淨係存喺你部電腦嘅瀏覽器入面，唔會寫入個 HTML 檔，亦都唔會上去 Google 雲端。換咗電腦、或者清咗瀏覽器資料，就要再填一次。
傾偈嗰度上載相或者影相嗰陣，會改用呢個型號。上面嗰個 Model 多數係純文字，睇唔到相。
Z.ai 免費嗰個係 glm-4.6v-flash（有速率限制，但夠用）；收費嗰個係 glm-5v-turbo（勁好多，但 Coding Plan 唔包，要另外課金）。
睇相要用另一條線？（例如 Coding Plan 唔包，要改用按量計嘅 API）

訂閱套餐同按量計費係兩個唔同嘅錢包。如果你個 Coding Plan 唔包睇相模型，就喺呢度填返開放平台嗰條 key，傾偈同排程照舊行套餐，淨係睇相嗰幾次先扣按量計嘅數。

⚠ 偵測到你用 file:// 直接開啟個 HTML。部分瀏覽器喺呢個情況下會拒絕連線。
請改用正規網址開啟（例如 GitHub Pages：https://你的用戶名.github.io/倉庫名/index.html），或者用本地伺服器 python -m http.server 8000 再用 http://localhost:8000 打開。GLM／z.ai 經實測支援任意 https 網址，GitHub Pages 完全用到。

推理模型嘅「內部思考」都要計入呢個上限。開住思考嘅話建議 20000–32000。呢個係上限唔係目標，用唔晒就唔會扣。

🔊 語音朗讀（TTS）

預設用瀏覽器內置語音，完全免費、唔使申請任何 key、唔使裝 server。Edge（Windows）同 iPhone／iPad Safari 內置有正宗廣東話女聲；桌面版 Chrome 多數淨係有普通話音。想部部機都靚聲，可以填埋下面嘅 Azure（微軟）免費 key。

⏳ 偵測緊你部機有咩語音…
（選擇性）用 Microsoft Azure 廣東話神經語音 — 每月 50 萬字免費

喺 portal.azure.com 開一個 Speech service（揀 F0 免費層），copy 個 KEY 1 同 Location/Region（例如 eastasia）貼落嚟。Region 留空就當 eastasia。
唔使填 Base URL。Portal 俾你嗰個 https://eastasia.api.cognitive.microsoft.com/ 唔係語音合成用嗰個網址；朗讀行嘅係 https://<region>.tts.speech.microsoft.com/cognitiveservices/v1，程式會用你個 Region 自動砌返出嚟。
呢個 key 同 API Key 一樣，淨係存喺你部機嘅 localStorage，唔會上網、唔會寫入 HTML。
