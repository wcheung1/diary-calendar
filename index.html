🤖 AI 排程助手

你講過嘅每一句、AI 排過嘅每個決定、同埋你之後每一次改動（喺行事曆度拖時間、改鐘數、刪走），全部自動記喺呢度。呢度就係佢學你 pattern 嘅材料。

呢份規則係 AI 睇完成個 Data Log 之後，總結出嚟嘅「你嘅使用說明書」。每次幫你排程之前，佢都會先讀呢度。你可以自己執，執完撳儲存。

同 AI 自由傾偈：可以一齊規劃時間表、傾偏好，甚至闲話家常。
對話記錄只存喺記憶體，關瀏覽器即消失（唔會入 Data Log）。

⚙ AI API 設定

🔒 呢三格資料淨係存喺你部電腦嘅瀏覽器入面，唔會寫入個 HTML 檔，亦都唔會上去 Google 雲端。換咗電腦、或者清咗瀏覽器資料，就要再填一次。
⚠ 偵測到你用 file:// 直接開啟個 HTML。部分瀏覽器喺呢個情況下會拒絕連線。
請改用正規網址開啟（例如 GitHub Pages：https://你的用戶名.github.io/倉庫名/index.html），或者用本地伺服器 python -m http.server 8000 再用 http://localhost:8000 打開。GLM／z.ai 經實測支援任意 https 網址，GitHub Pages 完全用到。
