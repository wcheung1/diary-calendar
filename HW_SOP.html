第 1 節

個 app 點樣認出「一堂」

明白呢四步，之後所有古靈精怪嘅情況你都解釋得返。

  1. 睇標題有冇「要含有」嗰幾隻字例：鋼琴課規矩嘅「要含有」係鋼琴。標題入面冇「鋼琴」就唔關佢事。填幾個字（逗號分開）就係全部都要中，唔係中一個就算。
  2. 再睇有冇撞「唔好含有」預設係功課,練習,溫習,温習,複習,預習,做卷,工作紙,特訓,補充。中咗任何一隻，即刻剔走。呢個就係點解「Charlotte 練習鋼琴」唔會被當成一堂鋼琴。
  3. 同一日有幾格都中？揀最長嗰格做正堂「婆婆帶Charlotte去佐敦」10 分鐘，「Charlotte DGJS 數學課」60 分鐘 → 正堂係後者。認錯嘅話，去課後功課 → 班別總覽，喺嗰張班別卡度親手指定。
  4. 時間窗只計最近 21 日嘅堂；再舊嘅唔會再派功課。另外「由邊日開始計功課」（hwSince）之前嘅，一律唔理。
⚑ 記住呢句
每一份功課，都係綁死喺「嗰一堂嗰一格」嘅。個 app 內部用「嗰格嘅編號＋功課個名」做標籤。 改時間、改名、拖去第二日 → 編號唔變，打過嘅勾唔會甩。 但係刪咗嗰格再重新開一格 → 係一個全新編號，舊嘅勾即刻作廢，成堆功課會彈返出嚟。
第 2 節

五條金科玉律

十次混亂入面有九次，都係違反咗下面其中一條。

  1. 要改一堂 → 直接改，唔好「刪咗再加」。喺行事曆度雙擊改時間，或者開「✎ 編輯」改。刪完再加會斷晒功課記錄（見第 1 節紅字）。
  2. 「上堂格」同「做功課格」要分得清清楚楚。做功課嗰格，標題一定要有「功課／練習／溫習／預習／工作紙」呢類字，個 app 見到先唔會當佢係一堂而再派多一份出嚟。
  3. 排功課時間，一定要喺功課卡撳「排時間」，唔好自己去時間表開格。用個掣開嘅格會綁死條線；自己開嘅格淨係靠個名夾，好易夾錯或者夾唔到。
  4. 加咗／改咗規矩之後，即刻返去睇「仲未做完」。規矩一改，過去 21 日所有堂都會即時重新計一次。爆咗量或者少咗嘢，嗰一刻就睇得出。
  5. 唔肯定就唔好撳紅色嘅掣。「💥 超級清除」同「⚡ 重設做預設規矩」冇得還原（Ctrl+Z 都救唔到 hwDone）。撳之前先撳「⬇ 匯出 JSON」。
第 3 節

上堂編排：加、改、減

全部都由時間表或者班別總覽入手。

3.1加一堂補堂／一次性嘅堂
  1. 時間表 揀日子 → ＋ 喺 X 新增項目
  2. 標題照抄返平時嗰堂嘅寫法，唔好改字眼例：一直用「Charlotte 鋼琴課」，補堂就照打「Charlotte 鋼琴課」。改咗做「鋼琴補堂」就冇咗「鋼琴」以外嘅問題……其實仲有「補」字唔喺排除名單度，所以呢個例子仲 OK；但如果你打「鋼琴補充練習」，就會中咗「補充」同「練習」兩個排除字，個 app 會當佢係做功課，唔會派功課出嚟。
  3. 填「指定完結時間」唔填就當 60 分鐘。填咗，同日有接送格嗰陣先分得出邊格係正堂。
  4. 唔好剔「呢個係做功課／練習嘅時段」
  5. 儲存 → 去課後功課睇「仲未做完」有冇多咗嗰份功課
✓ 成功嘅樣 「仲未做完」多咗一件，後面寫住「← 今日 上咗『Charlotte 鋼琴課』」。
3.2續排一個現有班（例如再排兩個月）
  1. 課後功課 → 🎓 班別總覽 → 攤開嗰個班
  2. 撳 推算多一堂，或者填個日期撳「排到嗰日為止」佢會由過往幾堂反推「逢星期幾、幾點、隔幾多日」。同時會連接送格一齊出——條件係最近一堂嗰啲接送格要貼實正堂（前一格完結時間＝正堂開始時間）而且唔長過 30 分鐘。
  3. 睇清楚草稿：日期、時間、幾多格
  4. 撳 同步落時間表 先至真係寫入
⚑ 草稿唔會儲存 未撳「同步落時間表」之前，refresh 或者閂咗個 app，啲草稿就冇晒。
3.3開一個全新班別（例如九月開學嘅常識科）

情況 A — 堂仲未排：

  1. 課後功課 → 班別總覽 → ＋ 開一個新班別
  2. 填：班別個名、時間表用嘅標題、逢星期幾、幾點、由邊日到邊日
  3. 要接送就填「邊個接送／去邊／去程幾耐／返程幾耐」留 0 就唔會排接送格。
  4. 「上完要跟進乜」逗號分開，例如 常識工作紙,溫習課文
  5. 揀死線點計 → 撳 開班＋排晒落時間表

情況 B — 堂已經喺時間表度排好咗：

  1. 同上，但一定要剔時間表已經排好，唔使再排
  2. 撳落去只會開規矩，唔會再整多啲格出嚟
⚑ 唔剔嗰個掣 個 app 會照排一次，你就會見到每堂都變咗兩格，跟住功課亦會出雙份。
✓ 開完即刻驗 個提示會話「喺時間表認返到 N 堂」。如果係「一堂都認唔到」，即係「上堂項目要含有」填錯咗——去班別卡改。
3.4改一堂嘅時間
  1. 時間表 揀返嗰格
  2. 雙擊個時間直接改，或者攤開個項目撳 ✎ 編輯
  3. 有接送格嘅話，接送格要自己手動跟住搬個 app 唔會自動搬接送。冇搬嘅話，下次「推算多一堂」就會用錯咗嘅偏移。
✓ 完全唔使擔心功課 改時間唔會影響任何打過嘅勾。連死線都會自動重新計。
3.5甩咗一堂／今次冇上到

如果嗰堂根本冇發生過：

  1. 時間表 攤開嗰格 → 🗑 刪除
  2. 跟住去課後功課確認嗰份功課消失咗
⚑ 如果你已經幫嗰堂嘅功課打過勾 刪咗嗰格，張打勾記錄就變成孤兒（無害，開機會自動清走），但係如果你之後又重新開返一格同一堂，功課會由零開始計。

如果堂上咗，但係老師話今次冇功課：唔好刪堂——去 4.3。

3.6一個班停咗／完咗
  1. 時間表 將將來嗰啲堂刪走用「📅 批量計劃」→ 動作揀「刪除」，一次過搞掂。
  2. 課後功課 → ⚙ 規矩 → 搵返嗰條 → 熄咗個開關熄咗好過刪咗：過去嗰啲打勾記錄仲喺度，第日再開返都得。
  3. 或者喺規矩度填「到邊日為止」，過咗就自動唔再派
⚑ 唔好淨係刪堂而唔熄規矩 規矩仲開住，過去 21 日入面淨低嗰幾堂會繼續彈功課出嚟。
第 4 節

功課：加、減、打勾

全部都喺 🤖 AI 排程 → 📚 課後功課。時間表嗰邊一格都唔使郁。

4.1一個班要多加／減少一份功課（長期）
  1. ⚙ 規矩：上完邊堂 ➜ 要跟進乜 → 攤開
  2. 搵返嗰條規矩 → 喺「跟進項目」度加多一行，或者刪走一行
  3. 「要做幾轉」可以填 2、3例：練習鋼琴一星期要練兩次，就填 2。功課卡會顯示「做咗 1／2 轉」。
  4. 返去「仲未做完」核對條數
⚑ 改功課個名 = 開一件新功課 打勾記錄用個名做標籤嘅一部分。將「大眾中文補充練習」改做「中文補充」，舊嗰件會即刻由清單消失（記錄留住），新嗰件由零開始。所以改名之前，最好等呢一輪功課做完先。
4.2加一件一次性練習（只做今次）
  1. ➕ 加練習俾佢（爸爸專用） → 攤開
  2. 打練習個名、要做幾轉、幾時之前做完、邊個做
  3. 撳 加落去
✓ 幾時用呢個而唔用規矩 「今次先要做」用呢個；「以後每次上完呢個班都要做」先用規矩。

要刪走：喺張功課卡右邊撳 ✕，即刻消失（呢類唔會入「交叉咗」名單）。

4.3今次真係冇功課
  1. 喺「仲未做完」搵返嗰件
  2. 撳右邊個 ✕
  3. 佢會搬去 🚫 交叉咗嘅 名單
✓ 撳錯咗都救得返 攤開「🚫 交叉咗嘅」，撳返轉頭就會返去「仲未做完」。
⚑ 唔好用「刪堂」嚟代替打交叉 刪堂會連埋接送格同記錄一齊亂。堂上咗就要留住嗰格。
4.4實體工作紙（風琴 folder）
  1. ➕ 加練習俾佢 → 落面「🗂 風琴 folder 工作紙」
  2. 喺「呢格叫咩名」打個名（留空就叫「工作紙 #N」）→ 揀邊個做
  3. 撳一個空格＝派呢格出去
  4. 撳一個已經派咗嘅格：上面有打名就係改名，冇打名就係收返
4.5打勾／撳錯咗
  1. 做完撳 ✓，做完一轉加一格
  2. 撳錯就撳 − 減返
  3. 做完嘅嘢會喺「✅ 啱啱做完」留 7 日 然後自動淡出唔係消失咗，係唔再阻住個畫面。
4.6想由某日開始重新計
  1. 班別總覽最底 → 由邊日開始計功課 填個日期 → 套用
  2. 嗰日之前上過嘅堂，一律唔會再彈功課
✓ 幾時用 例如新學期開始、或者你啱啱大改咗一堆規矩，唔想幾個禮拜前嘅舊堂突然湧一堆功課出嚟。呢個係最溫和嘅「重新嚟過」，唔會刪任何嘢，撳「清走限制」就恢復原狀。
第 5 節

排功課時間

呢個係兩個位交界嘅地方，最容易搞亂，所以獨立一節。

5.1正確做法
  1. 課後功課 → 喺張功課卡撳 排時間
  2. 自己揀日子時間，或者撳「幫我搵個位」佢會由今日行到死線，逐日試 16:00 / 17:00 / 19:00 / 20:00 / 20:30 / 10:30 / 14:30 / 15:30，撞到嘢就跳過。
  3. 時間表嗰邊即刻會多咗一格 做功課：XXX（琥珀色、30 分鐘）
✓ 兩邊即時同步 之後喺功課卡改時間，時間表嗰格會跟住郁；反過來喺時間表拖嗰格，功課卡都會顯示新時間。
5.2取消一個功課時段

喺功課卡撳 取消時段。件功課會返去「未排時間」，但唔會當成做完或者冇功課。

⚑ 唔好去時間表度直接刪嗰格 咁做張功課卡仲會以為排咗時間（因為佢會靠個名再夾一次）。用返個掣最穩陣。
5.3喺時間表度編輯「做功課」格
⚑ 呢個係最隱蔽嘅陷阱
如果你喺時間表攤開一格「做功課：XXX」，撳「✎ 編輯」，跟住手動剔走「呢個係做功課／練習嘅時段」再儲存 —— 個 app 就會當佢係一堂。跟住如果個名撞到某條規矩，就會派多一份功課出嚟，越滾越多。

做法：編輯呢類格嗰陣，個剔一定要留住。改時間嘅話，直接雙擊個時間改就得，唔使入編輯視窗。
第 6 節

出咗事點查

見到咩症狀 → 多數係咩原因 → 點解決。

症狀多數係因為點解決
同一份功課出咗兩件 同一日有兩格都認得做「一堂」，或者你開新班嗰陣冇剔「時間表已經排好」，堂變咗雙份 時間表睇返嗰日有冇重複嘅格，刪走多餘嗰格。或者去班別卡指定邊格先係正堂
一個班派咗兩套唔同嘅功課 有兩條規矩都認得同一堂（例如「普通話堂」同「普通話 Zoom 堂」） 去⚙ 規矩，喺其中一條嘅「唔好含有」加返個分辨字（例如 Zoom）
上咗堂，但功課冇出 ① 標題唔夠「要含有」嘅字
② 標題撞咗「唔好含有」（最常見：堂名入面有「補充」「練習」）
③ 嗰堂早過「由邊日開始計功課」
④ 嗰堂超過 21 日前
⑤ 條規矩熄咗，或者過咗「到邊日為止」		 逐項查。②嘅話，去⚙ 規矩將嗰隻字由「唔好含有」度剷走
打過勾，過幾日又彈返出嚟 你刪咗嗰堂再重新開過（新編號），或者你改咗功課個名 重新打返勾。以後改時間用「改」唔用「刪咗再加」
死線唔啱 死線係由「下次同一堂」推算：
next＝下堂前一日（冇下堂就上堂後 6 日）
week＝上堂後 7 日，但唔會遲過下堂前一日
none＝唔跟進		 將來嗰啲堂未排好，就會計錯。去班別總覽續排多幾堂，死線即刻自動啱返
「做功課」格被當成上堂 喺編輯視窗剔走咗「呢個係做功課／練習嘅時段」 開返嗰格，剔返個掣，儲存（見 5.3）
續排嘅堂冇帶埋接送格 最近一堂嘅接送格冇貼實正堂，或者長過 30 分鐘 去最近一堂嗰日，將接送格嘅完結時間調到啱啱等於正堂開始時間，再推算多一堂
功課清單突然爆量 多數係啱啱撳咗「⚡ 重設做預設規矩」，或者一次過續排咗好多堂落過去嘅日期 用「由邊日開始計功課」設做今日，即刻收乾淨，而且唔會刪任何嘢
第 7 節

唔好亂撳嘅掣

粒掣真正會做啲乜撳之前
💥 超級清除 清光所有功課記錄：未做完、過咗期、做完咗、交叉咗、爸爸加嘅練習、派咗嘅工作紙。同時將「由邊日開始計」設做今日。唔會郁規矩、行事曆、Data Log 先撳「⬇ 匯出 JSON」。冇得還原
⚡ 重設做預設規矩 用預設嗰 8 條，換走你現有全部規矩（包括你加過嘅班、接送組合、指定咗嘅正堂） 先匯出。你而家有 9 條，其中好幾條係自己改過
🗑 全部清走（Data Log） 清走成個 Data Log。General Rules 之後就冇材料重新提煉 先撳「⬇ 備份」
📅 批量計劃 → 刪除 將指定日期範圍內、同一個任務嘅項目全部刪走 日期範圍打清楚。刪堂會斷咗嗰啲堂嘅功課記錄
✓ 最穩陣嘅習慣 每個禮拜撳一次「⬇ 匯出 JSON」，個檔擺埋去雲端硬碟。一分鐘嘅事，換返所有後悔藥。
第 8 節

每次改完，30 秒檢查

改完上堂編排或者功課規矩，行一次呢張清單，基本上冇得亂。
